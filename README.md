# D-MPTCP-V3
Congestion Control-Based MPTCP Packet Scheduling in Hybrid Ad-Hoc Network

# abstract
Single-interface multi-hop Hybrid Ad-Hoc Networks (HANETs) challenge conventional multipath transport protocols due to mobility-driven Round-Trip Time (RTT) fluctuation and dynamically shared bottlenecks among subflows. Existing Multipath TCP (MPTCP) mechanisms typically assume strong path independence and loosely couple congestion control with packet scheduling, which limits their stability and fairness under rapid topology variation. This paper proposes DMPTCP, a delay-aware multipath transport framework that jointly designs congestion window regulation and packet scheduling. The delay-aware congestion controller (DAC) differentiates mobility-induced delay variation from congestion growth to stabilize subflow control, while the delay-based packet scheduler (DPS) coordinates packet assignment using congestion information and multi-next-hop routing states to mitigate path dominance and head-of-line blocking. DMPTCP is implemented in the Linux kernel and evaluated on a high-fidelity NS-3-based HANET platform with kernel-integrated transport stacks. Experimental results show that DMPTCP reduces end-to-end completion time by 15.57%–39.49% compared with representative TCP and MPTCP schemes, while maintaining stable congestion window dynamics and balanced multipath utilization under both moderate and extreme mobility.
